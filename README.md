# Interactive K-Nearest Neighbors and K-Means Cluster Visualizer
An interactive web application built using HTML, TailwindCSS and Javascript to visualize the working of KNN and K-Means Algorithms

## What it does
- Allows users to create custom labels (upto 5)
- Allows users to plot the data points in coordinates of their choice on the canvas 
- Step-by-step visualization of the algorithms with description for each step
